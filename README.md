# Daytrack

**Daytrack** is a web-based attendance and overtime management application designed to help employees manage their daily attendance, work schedules, journal entries, and overtime forms in one place.

## Features

- **User Authentication** – Secure employee login and registration.
- **Employee Management** – Superuser approval and access management.
- **Attendance Tracking** – Record daily attendance with photo uploads.
- **Attendance Calendar** – View and review saved attendance records.
- **Schedule Management** – Organize and monitor work schedules.
- **Journal Entries** – Keep track of daily notes and activities.
- **Overtime Forms** – Generate, save, print, and capture overtime form snapshots.
- **Cloud Storage** – Store records and uploaded photos online.

## Technologies Used

- HTML
- CSS
- JavaScript
- [Supabase](https://supabase.com/) – Authentication, database, and storage
- [GitHub Pages](https://pages.github.com/) – Website hosting
